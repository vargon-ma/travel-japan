# Issue 08 — Polish: แอนิเมชัน + responsive + loading state

> **Label:** `ready-for-agent`

## What to build

พาสสุดท้ายขัดเกลาประสบการณ์ใช้งานให้ลื่นและใช้ได้ทุกจอ

- แอนิเมชัน/ทรานซิชันนุ่มนวล: fade/slide ตอนกรองรายการ, hover การ์ด, เปิด/ปิดโมดัล
- responsive: กริด/แผนที่/ฟิลเตอร์/โมดัลแสดงผลดีบนมือถือ
- สถานะ "กำลังโหลด" ระหว่าง fetch ข้อมูล/เรต; ข้อความ empty state ที่เข้าใจง่าย
- ตรวจธีมให้สะอาด มินิมอล สว่าง สม่ำเสมอทั้งเว็บ

> หมายเหตุ: เป็นงาน cross-cutting (ไม่ใช่ vertical slice แท้) — ถ้าทำพาสนี้ทีหลังให้ไล่ทุกหน้าจอ/ทุก state

## Acceptance criteria

- [ ] กรอง/เปิดโมดัล/hover มีแอนิเมชันนุ่มนวล ไม่กระตุก
- [ ] ใช้งานได้ดีบนมือถือ (กริด, แผนที่, ฟิลเตอร์, โมดัล)
- [ ] มี loading state ระหว่างโหลดข้อมูล/เรต และ empty state ชัดเจน
- [ ] ธีมสะอาด/สว่าง สม่ำเสมอทั้งเว็บ
