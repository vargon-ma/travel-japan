# Issue 05 — โมดัลรายละเอียด + แกลเลอรีรูป

> **Label:** `ready-for-agent`

## What to build

คลิกการ์ด (หรือลิงก์ใน popup แผนที่) เปิดโมดัลแสดงรายละเอียดครบของ entry

- คำอธิบาย (ไทย), ชื่อ TH + JA/โรมาจิ
- ลิสต์สินค้า/เมนูตัวอย่างพร้อมราคา ¥ และ ฿ (สำหรับหมวดเกม แสดงว่ามือ 1 / มือ 2)
- ที่อยู่ (ไทย + ญี่ปุ่น) + แผนที่ย่อตำแหน่งร้าน
- ลิงก์แหล่งอ้างอิง (`sourceUrl`) ของ entry
- แกลเลอรีรูปหลายรูป (เลื่อนดูได้); ถ้าไม่มีรูปจริงใช้ placeholder
- ปิดโมดัลได้ (ปุ่ม/คลิกพื้นหลัง/Esc)

## Acceptance criteria

- [ ] คลิกการ์ดเปิดโมดัลที่มีรายละเอียดครบตามรายการข้างบน
- [ ] สินค้า/เมนูแสดงราคา ¥ และ ฿; เกมระบุมือ 1/มือ 2
- [ ] แกลเลอรีเลื่อนดูหลายรูปได้ (หรือ placeholder เมื่อไม่มีรูป)
- [ ] มีลิงก์แหล่งอ้างอิงที่คลิกไปต้นทางได้
- [ ] ปิดโมดัลได้หลายวิธี
