# Issue 04 — แผนที่ Leaflet sync กับ view

> **Label:** `ready-for-agent`

## What to build

แผนที่อินเตอร์แอคทีฟ (Leaflet + OpenStreetMap) ที่ปักหมุดทุก entry และ sync กับฟิลเตอร์/ค้นหาปัจจุบัน

- โหลด Leaflet จาก CDN (ไม่ต้องใช้ API key)
- ปักหมุดทุก entry ที่อยู่ใน view model ปัจจุบัน (เคารพฟิลเตอร์จาก Issue 03 ถ้ามีแล้ว)
- คลิกหมุด → popup แสดงชื่อ (TH+JA) + รูปย่อ + ราคาเริ่มต้น (¥/฿) + ปุ่ม/ลิงก์เปิดโมดัลรายละเอียด
- เมื่อฟิลเตอร์/ค้นหาเปลี่ยน หมุดบนแผนที่อัปเดตให้ตรงกับกริด

## Acceptance criteria

- [ ] แผนที่แสดงผลและปักหมุดทุก entry ที่ผ่านฟิลเตอร์
- [ ] คลิกหมุดเห็น popup (ชื่อ+รูป+ราคา+ทางเปิดโมดัล)
- [ ] กรอง/ค้นหาแล้วหมุดบนแผนที่ sync กับกริด
- [ ] ไม่ต้องใช้ API key; โหลด lib จาก CDN
