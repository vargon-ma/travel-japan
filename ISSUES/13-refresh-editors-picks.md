# Issue 13 — คัด Editor's Pick ใหม่ 8–10 ร้าน ให้ครบแนว + กระจายเมือง

> **Label:** `ready-for-agent`

## Parent

`PRD-dataset-expansion.md`

## What to build

รีเฟรช Featured strip หลังของครบ ให้เป็น "ตัวอย่างที่ดีที่สุดของแต่ละแนว" ไม่ใช่กระจุกแลนด์มาร์ก/อาหารเหมือนเดิม — คนเปิดมาเจอความหลากหลายทันที

- คัด `editorsPick: true` ใหม่ให้เหลือ **8–10 ร้าน** จาก ~49 ร้าน
- กติกาสมดุล: อย่างน้อย 1 pick ต่อหมวดที่มีของเด็ดจริง (รวม cosplay/electronics/shopping/cafe ที่เดิมไม่มี) + กระจายเมือง (ไม่โตเกียวล้วน)
- ทุก pick มี `editorsPickReason` สั้น ๆ ที่ **จับต้องได้** (ไม่ใช่ "ดีมาก" ลอย ๆ)
- เกณฑ์: "ถ้าเพื่อนถามว่าไปญี่ปุ่นครั้งแรกต้องไปไหน คุณตอบร้านนี้"

## Acceptance criteria

- [ ] มี entry ติดธง `editorsPick: true` รวม 8–10 ร้าน
- [ ] ครอบคลุมอย่างน้อย 1 ร้านต่อหมวดที่มีของเด่นจริง + มีมากกว่า 1 เมือง
- [ ] ทุก pick มี `editorsPickReason` ที่เฉพาะเจาะจง จับต้องได้
- [ ] Featured strip แสดงผลถูกต้องตาม picks ใหม่; `npm test` เขียว
- [ ] ไม่มีการแต่งเรตติ้ง/รีวิว (ใช้เหตุผลบรรณาธิการเท่านั้น)
