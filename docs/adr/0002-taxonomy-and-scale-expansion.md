# ขยายอนุกรมวิธานเป็น 8 หมวด และสเกลเป็น ~50 รายการ

PRD เดิมจงใจให้ v1 เล็ก: 5 หมวด, ~15 Entry (~3 ต่อหมวด) แต่ผู้ใช้ต้องการให้เว็บ "แน่นและน่าสนใจ" กว่านี้ เราจึงตัดสินใจ**เพิ่มเป็น 8 หมวด** (เพิ่ม `anime-goods`, `cafe`, `shopping` จากเดิม 5) และ**ขยายเป็น ~50 Entry** โดยคง 3 เมืองเดิม (tokyo/osaka/kyoto) เพื่อโฟกัสความลึกต่อเมือง

## Considered Options

- **คง 5 หมวด/15 รายการตาม PRD** — ปฏิเสธเพราะไม่แก้ปัญหาหลักที่ผู้ใช้รายงาน ("ข้อมูล/สถานที่น้อย")
- **เพิ่มเมืองด้วย (6-10 เมือง)** — ปฏิเสธ เลือกคง 3 เมืองเพื่อให้ค้นข้อมูลได้ลึกและแผนที่ไม่กระจายเกินไป

## Consequences

- `Category` เป็น closed set ที่ตอนนี้มี 8 ค่า — โค้ดที่ map หมวด→สี/ไอคอน/ชื่อไทย ต้องครบทั้ง 8
- Entry schema ขยายฟิลด์ใหม่: เวลาเปิด, สถานี/การเดินทาง, `tags[]`, `tips[]`, `priceLevel` (คำนวณได้), `bestTime`, `googleMapsUrl`, `editorsPick` (+เหตุผล) — ดู [CONTEXT.md](../../CONTEXT.md)
- **ไม่ทำเรตติ้งเป็นตัวเลขบนเว็บ** เพราะจะกลายเป็นข้อมูลกุที่ดูน่าเชื่อ ใช้ปุ่มลิงก์ไป Google Maps ให้เรตติ้งจริงอยู่ที่ต้นทางแทน
- ข้อมูลทุก Entry ต้องผ่านการค้นเว็บจริง (พิกัด/ราคา/เวลา) และอ้างอิงแหล่ง — ช้ากว่าแต่กันข้อมูลมั่ว
- ส่งมอบแบบแบ่งเฟส: เฟส 1 รีดีไซน์ Vivid + ฟิลด์ใหม่บน 15 Entry เดิม → เฟส 2 ค้นข้อมูลขยายจน ~50
