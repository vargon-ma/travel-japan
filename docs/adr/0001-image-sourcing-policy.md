# ขยายนโยบายแหล่งรูปภาพ: Wikimedia + แหล่งฟรีอื่น

เดิม CLAUDE.md กำหนดให้รูปภาพมาจาก Wikimedia Commons เท่านั้น (หรือ placeholder) เพื่อความบริสุทธิ์ด้านลิขสิทธิ์ แต่ผลคือมีรูปจริงแค่ ~6 จาก 15 Entry ที่เหลือเป็น placeholder อิโมจิ ทำให้เว็บดู "เงียบ/ราคาถูก" เราจึง**ขยายนโยบายให้ใช้แหล่งรูปฟรีอื่นที่อนุญาตเชิงพาณิชย์ได้ด้วย** (เช่น Unsplash, Pexels) โดยทุกรูปต้องเก็บ `source`/`credit`/`license` และให้เครดิตเสมอ แม้บางใบอนุญาต (Unsplash/Pexels) จะไม่บังคับก็ตาม

## Consequences

- เกิดการพึ่งพา CDN ภายนอกเพิ่มขึ้น (นอกเหนือจาก Wikimedia) — ยอมรับได้สำหรับ static site เชิงการศึกษา
- ต้องอัปเดตข้อความนโยบายรูปภาพใน CLAUDE.md ให้ตรงกัน เพื่อกันความเข้าใจผิดในอนาคต
- เป้าหมายใหม่: ทุก Entry มีรูปจริงอย่างน้อยหนึ่งใบ (เลิกพึ่ง placeholder เป็นค่าเริ่มต้น แต่ยังคงโค้ด placeholder ไว้เป็น fallback กันรูปแตก)
