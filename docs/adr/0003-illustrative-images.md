# ใช้ "ภาพประกอบ" (illustrative image) เมื่อหารูปจริงเสรีไม่ได้

หลาย Entry (ร้านเล็กในอากิฮาบาระ ร้านซูชิ/ปลาไหล สาขาดองกี้เฉพาะ) **ไม่มีรูปตัวร้านจริงแบบเสรีเลย** ทำให้เว็บเต็มไปด้วย placeholder อิโมจิ (จริง ๆ คือ 22 จาก 28 Entry ยังไม่มีรูป) เราจึงตัดสินใจ: เมื่อหารูปจริงเสรีไม่ได้ ให้ใช้ **รูปตัวแทนบริบทที่ถูกลิขสิทธิ์** (อาหารจานเด่น/ย่านนั้น จาก Wikimedia/Unsplash/Pexels) พร้อมติดธง `isIllustrative: true` ให้ UI แสดงป้าย "ภาพประกอบ" อย่างชัดเจน — เลือกความ "มีชีวิตแต่ซื่อสัตย์" แทนทางเลือก A (รูปจริงเท่านั้น ปล่อย placeholder ครึ่งเว็บ)

## Considered Options

- **A) รูปจริงเท่านั้น** — ซื่อสัตย์สุด แต่เหลือ placeholder เกินครึ่ง ขัดเป้าหมาย "เว็บดูมีชีวิต"
- **B) ภาพประกอบมีธง (เลือก)** — ลำดับความพยายามต่อ Entry: (1) รูปจริงเสรี → (2) ภาพประกอบเสรี + `isIllustrative` → (3) placeholder ตามหมวด
- **C) รูปจาก Google/เจ้าของร้าน** — ผิดกฎลิขสิทธิ์โปรเจกต์ (ADR-0001) ตัดทิ้ง

## Consequences

- schema เพิ่มฟิลด์ `isIllustrative` (boolean, optional) บนรายการใน `images[]` และ UI ต้องเรนเดอร์ป้าย
- ยังผูกกับ ADR-0001: ทุกรูป (จริงหรือประกอบ) ต้องเก็บ `source`/`credit`/`license` เสมอ
- ธงนี้ทำให้ความ "เป็นภาพประกอบ" กลายเป็น **ข้อมูล** ที่ตรวจสอบ/แสดงได้ ไม่ใช่การหลอกผู้ใช้
